# Payday Crunch Map
앱 이름: 텅장달력 / Payday Crunch Map

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
월세·카드값·구독료 출금일이 월급일 전에 몰리는 날, 잔고가 가장 얇아지는 날을 달력으로 찍어줘요

## Problem
월급일, 월세 이체일, 카드 결제일, 보험·구독 자동이체일이 서로 달라서 월 중 어느 구간에 잔고가 바닥나는지 감이 안 온다. 은행 앱은 잔고만 보여주고, 다음 한 달의 출금 순서는 보여주지 않는다.

## Target Users
월급 통장 하나로 고정지출을 돌리는 사회초년생과 자취생

## Core Features
1. 월급일·금액과 본인이 등록한 출금 항목(이름·금액·날짜)을 입력하고 항목은 자유롭게 추가·삭제
2. 등록한 항목이 달력에 자기 이름으로 찍히고 날짜별 예상 잔고를 표시
3. 예상 잔고가 가장 낮은 날과 월급 전 최저 구간을 강조
4. 출금일을 옮기면 최저 잔고가 얼마나 달라지는지 시뮬레이션(리워드 광고 뒤 공개)
5. 다음 달 달력으로 자동 이월

## Goal
이 앱을 쓰고 나면 사용자는 월세 이체일을 월급일 다음 날로 옮기거나 카드 결제일을 변경해 월중 최저 잔고를 늘린다.

## User Payoff
- 매번 얻는 결과물: 날짜별 예상 잔고 달력과 '이번 달 최저 잔고일' 카드
- 앱이 더하는 것: 항목들을 날짜순으로 누적해 사용자가 직접 계산하지 않던 월중 최저 잔고 시점과 날짜 이동 효과를 계산한다.

## Monetization
- Model: ads
- Estimated MRR: 월 2,026원(출시 직후 DAU 15, 배너 노출 2회 가정)
- Reasoning: 달력 하단에 배너를 두고, 출금일 이동 시뮬레이션은 리워드 광고 뒤에 둔다. 기저선 DAU 15 × 노출 2회 × 30일 × 2.648원/1,000 × 0.85 ≈ 2,026원이다. 외부 채널 근거가 없어 DAU를 올리지 않았다.
- Estimated DAU: 15
- Monthly Net Revenue (KRW): 2026
